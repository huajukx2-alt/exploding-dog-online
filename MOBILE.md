# Install on iOS and Android

Live URL: https://exploding-dog-verified.onrender.com

Android: open in Chrome, press the game's install button, and accept the browser
prompt. If no prompt is offered, open the browser menu and choose Install app or
Add to Home screen.

iPhone/iPad: open in Safari, press Share, Add to Home Screen, then Add.
Launch from the new dog icon. In-app chat browsers may require opening the link
in Safari or Chrome first.

This release is an installable web app (PWA), not an APK or an App Store release.
The installed app has its own icon and standalone window. Internet is required
for accounts, bots and multiplayer because the game runs on the server.
When offline, the app shows a reconnect page; it never caches account responses.
Assets update from the server on each launch. Installing may create separate
browser storage: log in with your existing account if needed.

Validation: automated install-prompt and iOS guidance tests, PNG manifest icon
dimensions, offline fallback and API/socket cache exclusion, plus the game suite.
Physical iPhone/Android installation has not been tested in this environment.
